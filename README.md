## 🛒 Старые версии Melbis Shop 6

В этом репозитории также сохранены ранние сборки 6-й линейки. Основные возможности и особенности архитектуры MS6:

* 👥 **Многопользовательский интерфейс:** возможность распараллеливания и гибкого распределение задач между сотрудниками, всевозможные настройки доступа к данным, сохранность коммерческой информации.
* ⚡ **Быстрая работа с большими массивами данных:** сотни поставщиков, сотни тысяч товаров, тысячи характеристик товаров. Пакетная обработка прайс-листов.
* 📝 **Удобное и быстрое формирование описаний товаров:** работа с изображениями на ходу, уникальный HTML-редактор.
* 📈 **Масштабируемость системы:** максимум настраиваемых полей и технологических опций, плюс интегрированный веб-браузер обменивающийся данными с приложением. При реализации веб-модулей управление магазином, как через приложение так и через любой веб-браузер.
* 🛍️ **Заказы и покупатели:** настраиваемые поля, опции, опции опций. Все что нужно, чтобы сформировать свою уникальную бизнес-логику по обработке и выполнения заказов.
* 🌍 **Мультиязычность:** дополнительная структура для удобной работы с автоматическим переводом разных элементов магазина.
* 🔍 **Расширенный запрос данных:** удобные и функциональные фильтры для запроса только нужных данных. Написание собственных шаблонов запросов, вплоть до прямых SQL-запросов.
* 📊 **Встроенная система профессиональных отчетов FastReport:** Создание собственных форм для построения динамических отчетов.
* 🛠️ **Мощная среда разработки:** удобный и быстрый доступ к данным, функциональный редактор кода с автозавершением, загрузка chm-справочников, описание структуры БД, отладчик SQL-запросов.
* 🧩 **Отличный фреймверк для создания модулей магазина:** очень простой, документированный с автоматической системой кеширования результатов работы.
* 📱 **Простой и наглядный демонстрационный магазин:** Полностью сформированный минимальный бизнес-процесс с готовым набором модулей витрины на базе шаблонов Bootstrap 4.

## 🕰️ Melbis Shop 5 — уже часть истории

**Melbis Shop 5** — это более ранняя версия нашей программы. Сейчас она устарела и распространяется бесплатно, но без какой-либо технической поддержки. 

Эта версия была разработана в 2002 году и за это время сотни предпринимателей создали с ее помощью свой первый интернет-магазин. Нам очень приятно, что наш продукт оказался востребованным и помог сделать многим предпринимателям свои первые шаги в электронной коммерции. Безусловно, мир программного обеспечения устроен таким образом, что период почти в 20 лет является очень и очень большим сроком. 

🌐 **Официальный сайт:** [melbis.com](https://melbis.com)

### 🧩 Состав программного комплекса MS5

* 🖥️ **Melbis Shop** — это программа, в которой администратор формирует прайс-лист, структуру каталогов, задает параметры магазина, контролирует его работу. Также этой программой пользуются менеджеры, которые набивают описания товаров и передают их в формате MS5.
* 📊 **Melbis Shop Agent** — в этой программе администратор отслеживает движения покупателей по магазину в реальном времени, а также получает уникальные статистические отчеты, например "Заказы с доменов" или "Заказы по поисковым фразам". Это программа входит в базовый дистрибутив Melbis Shop.
* ☁️ **Melbis Shop Script** — это php-скрипты, которые устанавливаются на хостинге и, собственно, обеспечивают работу интернет-магазина (интернет-витрина). Информацию по установке серверной части можно найти здесь: документация Melbis Shop 5.
* 🛒 **Melbis Shop Trader** — это windows-программа для менеджеров интернет-магазина для автоматизации приема и обработки заказов. Программа позволяет принимать и сохранять заказы в т.ч. без подключения к Интернет, а потом передавать их на сервер в единый центр.
* 🔄 **Melbis Shop Spider** — эта windows-программа помогает товароведам, независимо от администратора магазина, своевременно обновлять остатки и цены товаров. Может работать в автоматическом режиме, самостоятельно обновляя данные из программ, например 1С.
* ⚙️ **Melbis Shop Server** — демо-скрипты с преднастроенным сервером, предназначены для того, чтобы посмотреть, как магазин будут видеть покупатели. Вы сможете добавлять товары, создавать дизайн магазина, подключать отдельные php-модули.
