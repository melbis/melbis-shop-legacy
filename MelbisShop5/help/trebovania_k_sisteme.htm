Требования к системе

 

Клиентская часть:


1) Операционная система: Windows 98/Me/2000/XP/Vista;
2) Процессор: не ниже класса Penitum II;
3) Минимальное разрешение видеокарты: 1024x768х16;
4) Минимальное место на жестком диске (без учета данных магазина): 50 Мб;
5) Подключение к Интернет: не хуже модемной связи со скоростью 14400 кбит/с;
6) Совместимость: возможность установки и беспрепятственная работа модулей BDE (Borland Database Engine) и Microsoft ActiveX DHTMLEdit.

7) Ограничение: при использовании системы FAT32 на жестком диске, максимальное количество файлов (изображений к товарам) ограничено до 18 тыс.

 

 

Серверная часть :


1) Операционная система: Windows, Linux, FreeBSD;
2) Процессор: не ниже класса Penitum II;
3) Минимальное место на жестком диске (без учета данных магазина): 2 Мб;

4) Возможность задания настроек сервера через файл .htaccess и наличие модуля mod_rewrite;
5) Установленный интерпретатор PHP кода версии от 4.3.10, 5.x со стандартными модулями: iconv, mysql, xml, zlib, gd 2.0. Допустимо использование режима SafeMode;

6) СУБД MySQL версии 3.23.х, 4.х, 5.0 с возможностью создания временных таблиц (CREATE TEMPORARY TABLE).
7) Возможность установить необходимые права для php-скриптов, обеспечивающие создание и удаления других файлов и директорий любой вложенности;

8) Возможность загружать файлы на сервер через php-скрипты;

9) Возможность установки и запуска cron-скриптов.

 

Дополнительные рекомендации при выборе хостинга:


1) Желательно, чтобы PHP мог при необходимости продлить время выполнения скрипта командой set_time_limit;
2) Желательно, чтобы письма можно было отправлять не только через PHP функцию mail, но и через сокет-соединение;
3) Желательно, чтобы в СУБД MySQL была разрешена команда быстрой загрузки данных: LOAD DATA LOCAL INFILE;
4) Желательно, чтобы велось автоматическое резервное копирование вашего аккаунта.
