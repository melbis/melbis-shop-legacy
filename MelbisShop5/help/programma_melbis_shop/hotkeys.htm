Горячие клавиши

Для обеспечения возможности быстрого доступа к функциям программы реализованы "горячие клавиши", которые позволяют быстро вызвать необходимое окно или выполнить определенное действие.

 

Главное Меню

  • F1 : Руководство пользователя.
  • <Ctrl>+F1 : Реестр магазинов.
  • F2 : Отправка данных.
  • <Ctrl>+F2 : Параметры подключения.
  • <Shift>+<Ctrl>+F2 : Журнал интернет-соединений.
  • <Shift>+F2 : Обновить прайс-лист с сервера.
  • F3 : Калькулятор.
  • <Ctrl>+F3 : Автовычисления.
  • F4 : Менеджер характеристик.
  • <Ctrl>+F4 : Назначить характеристику группе товаров.
  • F5 : Менеджер параметров.
  • <Ctrl>+F5 : Назначить параметр группе товаров.
  • F6 : Менеджер скидок.
  • <Ctrl>+F6 : Назначить скидку группе товаров.
  • F7 : Импорт/обновление в формате TXT.
  • <Ctrl>+F7 : Экспорт в формате TXT.
  • F8 : Импорт в формате MS5.
  • <Ctrl>+F8: Экспорт в формате MS5.
  • F9 : Общие настройки магазина.
  • <Shift>+<Ctrl>+F9 : Валюты используемые для задания цен.
  • <Ctrl>+F9 : Формирование прайс-листа в Excel.
  • F10 : Картотека заказов.
  • <Ctrl>-F10: Каталог покупателей.
  • F11 : Партнерская программа.
  • <Ctrl>-S : Сбор буфера базы данных.

Операции с товарами

  • <Ins> : Добавить.
  • <Del>: Удалить.
  • <Enter> : Редактировать.
  • <Ctrl>+С : Копировать.
  • <Ctrl>+V : Вставить.
  • <Ctrl>+X : Вырезать.
  • <Ctrl>+D : Дублировать.
  • <Ctrl>+<Вверх> : Переместить вверх.
  • <Ctrl>+<Вниз> : Переместить вниз.
  • <Ctrl>+A, <+>: Выделить все.
  • <Ctrl>+Q, <->: Снять выделение.
  • <Ctrl>+I, <*>: Инверсия выделенного.
  • <Ctrl>+1 : Все товары со статусом "На складе".
  • <Ctrl>+2 : Все товары со статусом "Отсутствует".
  • <Ctrl>+3 : Все товары со статусом "Ожидается".
  • <Ctrl>+4 : Все товары со статусом "Под заказ".
  • <Ctrl>+0 : Все товары с количеством ноль.
  • <Пробел> : Выделить позицию.

Картотека заказов

  • <Ctrl>+R : Загрузить/обновить заказы с сервера.
  • <Ctrl>+S : Сохранить информацию на сервер.
  • <Ctrl>+F : Поиск заказов.
  • <Ctrl>+F1 : Назначить статус "Принят к выполнению".
  • <Ctrl>+F2 : Назначить статус "В процессе доставки".
  • <Ctrl>+F3 : Назначить статус "Выполнен".
  • <Ctrl>+F4 : Назначить статус "Аннулирован".
  • <Ctrl>+F5 : Назначить статус "Оплата принята".
  • <Ctrl>+F6 : Назначить статус "Оплата не принята".
  • Ins : Создать новый заказ.
  • Del : Удалить выбранные заказы.
  • F4 : Редактировать выбранный заказ.
  • F7 : Экспорт заказов в формате MS5.
  • F8 : Показать счет заказа.
  • F9 : Вернуть исходные статусы заказам.
  • <Ctrl>+F9 : Клонирование заказа.
  • F10 : Совокупный отчет найденных заказов.
