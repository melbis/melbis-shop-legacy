Подключение собственных PHP-модулей

По мере развития интернет-магазина может возникнуть необходимость реализации собственных нестандартных функций. Поскольку скрипты поставляются с открытым кодом, есть вариант их самостоятельной доработки, но в этом случае надо помнить, что в случае выхода новой версии программы, вам либо придется отказаться от нее, либо еще раз реализовать необходимые исправления в обновленных скриптах. Чтобы разрешить данную ситуацию, мы реализовали специальную функцию в Melbis Shop, которая позволяет автоматически подключить дополнительные модули с набором необходимых функций. При этом нет необходимости править скрипты, достаточно разместить необходимый модуль в папке php_mod на сервере. Ниже будет рассмотрен пример, который реализует возможность вывода последней даты модификации прайс-листа магазина.

 

1. Создайте файл с именем mod_price.php со следующим содержимым:

<?php

function mod_price($mPageType)

{

global $gTpl, $gOptions;

$filename = './files/price.zip';
$echo_string = date($gOptions['main_fmt_date_time'], filemtime($filename));

 

$gTpl->Assign('LASTUPDATEPRICE', $echo_string);

}

?>

Для того чтобы система смогла определить, что данный файл является модулем, а не вспомогательным файлом, необходимо чтобы файл обязательно начинался с приставки "mod_". Для работы с шаблонами магазина, необходимо объявить глобальную переменную $gTpl, а результаты функции выводить с помощью метода Assign(название_ключа_в_шаблоне, значение_ключа). В файле обязательно должна присутствовать функция, название которой совпадает с именем файла (без расширения), в нашем случае, это функция mod_price. Эта функция будет вызвана автоматически сразу после присоединения модуля. Кроме этого, эта функция должна иметь один входной параметр, в примере определяется как переменная $mPageType. В данную переменную подставляется код скрипта, например index, dir, goods и т.п. таким образом, появляется возможность определить какой именно скрипт вызвал этот модуль.

 

2. Сохраните это файл в папку php_mod на сайте магазина. Данная папка автоматически сканируется скриптами на наличие в ней дополнительных модулей.

 

3. Используя редактор шаблонов, необходимо поместить в соответствующий шаблон ключ в фигурных скобках (для примера, это будет {LASTUPDATEPRICE}). На место этого ключа и будет выводиться необходимая информация. Также, в нашем случае, можно создать раздел или текстовый блок в наименование или содержимое которого вставить также этот ключ {LASTUPDATEPRICE}.
